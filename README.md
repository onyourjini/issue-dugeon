## How to Run Game
- Choose a quest.
- Inspect Trace to find a clue.
- Use Apply Patch or Run Tests to damage the bug.
- Keep your HP above zero. The bug attacks you after some actions.
- Win to earn XP and gold. If you lose, you can try again.
